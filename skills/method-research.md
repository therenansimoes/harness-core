## Research before you change code

- State the question in one line. If you cannot, you are not ready to search.
- Prefer primary sources: repo files, ledger, docs in-tree, then external docs. Cite path or URL.
- Separate **fact** (observed) from **inference**. Do not treat blog posts as specs.
- Seek one counter-example before accepting a fix. If none found, say so.
- End with a short decision: keep / change / escalate — and what evidence would reverse it.
- Do not start `edit_file` until research produced a concrete hypothesis or plan step.

## Done when
- Question stated, primary sources cited, fact/inference labelled, counter-example checked, decision recorded (keep / change / escalate).
