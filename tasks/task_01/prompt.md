Crie um arquivo `README.md` no diretório atual documentando uma ferramenta CLI
fictícia chamada `csvpeek`, que imprime estatísticas de um arquivo CSV.

O README precisa ter, nesta ordem, os cabeçalhos markdown de nível 2:

## Instalação
## Uso
## Opções
## Exemplo

Requisitos:
- A seção `## Uso` deve conter um bloco de código com a linha `csvpeek dados.csv`.
- A seção `## Opções` deve documentar exatamente três flags: `--rows`, `--cols`, `--json`.
- A seção `## Exemplo` deve conter um bloco de código com saída de exemplo.
- O arquivo inteiro deve ter no mínimo 20 linhas.
